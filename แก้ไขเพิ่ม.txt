Tooltip บน ต{x} / ส{x}:
  - เมื่อนำเมาส์ไปวางที่ ต{x} (ถูกตรง) ถ้า x > 0 → แสดง popup วันที่ของงวดที่ถูกตรง ทั้งหมด (สีทอง)
  - เมื่อนำเมาส์ไปวางที่ ส{x} (ถูกสลับ) ถ้า x > 0 → แสดง popup วันที่ของงวดที่ถูกสลับ ทั้งหมด (สีเขียว)
  - ถ้า x = 0  ไม่มี tooltip (ไม่มีอะไรดูเพิ่ม)
  - ตัวเลขที่มี tooltip จะมีขีดเส้นใต้แบบจุด (dotted underline) และ cursor pointer เพื่อบอกว่าดูเพิ่มได้
  - Tooltip แสดงแบบ floating popup สไตล์ glass card ลอยเหนือ mouse พร้อมลำดับและวันที่งวด
